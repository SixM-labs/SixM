# Spec D6: HTTP handler `req.address` and `req.setCancelHandler`

Add `req.address` and `req.setCancelHandler(fn)` to `SetHttpHandler` in both Lua (`sixm-lua`) and JavaScript (`sixm-js`), wired to `sixm-net` client disconnect and timeout cancellation.

## 1. Core & Network Cancellation (`crates/sixm-core`, `crates/sixm-net`)

- **`crates/sixm-core/src/runtime.rs`**:
  - Add `pub address: String` to `WebRequest` (`"ip"` string of the effective client IP — proxy-resolved via `sv_proxyIPRanges` when applicable, e.g. `"127.0.0.1"`, NOT `"ip:127.0.0.1"`).
  - Add default method on `ScriptRuntime`:
    ```rust
    /// Notifies the runtime that pending HTTP request `id` was canceled
    /// (client disconnected or timed out) before a response was sent.
    fn cancel_http_request(&self, _id: u64) {}
    ```
- **`crates/sixm-net/src/web.rs`**:
  - Expose `pub fn is_canceled(&self) -> bool` on `WebResponder` returning `self.sender.is_closed()`.
  - Ensure client disconnects while awaiting a script HTTP handler cancel promptly: when hyper drives the response future (`oneshot::Receiver<WebResponse>`), closing the TCP socket drops `rx`, making `sender.is_closed()` return `true`. Verify/ensure TCP disconnect drops the in-flight service future cleanly on both Linux and Windows (no extra `spawn` leak).

## 2. Server HTTP State & Cancel Dispatch (`crates/sixm-server/src/web.rs`, `manager.rs`)

- **`crates/sixm-server/src/web.rs`**:
  - Populate `WebRequest.address = responder.client_ip().to_string()` when forwarding to a resource's HTTP handler in `handle_web`.
  - In `expire_web(&self, now: Instant)`:
    - Sweep BOTH expired requests (`elapsed >= timeout`) AND requests whose `responder.is_closed()` is `true` (client disconnected before `reply_web` finished).
    - Collect `(id, resource_name, responder, timed_out)` for removed entries BEFORE borrowing script runtimes (keep `self.web.pending` borrow cleanly dropped!).
    - For timed-out requests where `!responder.is_closed()`, send `504 Gateway Timeout`.
    - For every removed pending request (client disconnect OR timeout), call `cancel_http_request(id)` on the target resource's runtimes!
    - Also in `stop_resource` cleanup (`cancel_web_for(resource)` / stopping runtimes): either cancel pending handlers cleanly with `503` (already done) + let runtime `shutdown()` drop all JS/Lua handler references.

## 3. Lua & JS Runtime Integration (`crates/sixm-lua/src/web.rs`, `crates/sixm-js/src/web.rs`)

- **`crates/sixm-lua/src/web.rs`**:
  - Set `req.set("address", request.address.as_str())` on the `req` table passed to the `SetHttpHandler` callback.
  - Store active per-request cancel handlers on `LuaRuntime` (e.g. `http_cancels: RefCell<BTreeMap<u64, Function>>` or stored in `PendingWeb` / `LuaRuntime`).
  - Expose `req.setCancelHandler(fn)`: stores `fn` (error if not a function) for this `id` ONLY while the request is still open (if already replied/canceled, ignore or no-op safely).
  - Clear the stored cancel handler automatically as soon as `res.send(...)` is called for `id`.
  - Implement `ScriptRuntime::cancel_http_request(&self, id: u64)` in `crates/sixm-lua/src/runtime.rs`: remove `id` from `http_cancels`; if present, call the handler safely (logging script error via `tracing::error!(target: "sixm::script", "[{}] ...", self.resource)` without panicking).
- **`crates/sixm-js/src/web.rs`**:
  - Set `req.set("address", request.address.as_str())` on the `req` object.
  - Expose `req.setCancelHandler(fn)` accepting a `Function` (`Persistent<Function<'static>>`), stored keyed by `id` while open and cleared when `res.send(...)` completes.
  - Implement `ScriptRuntime::cancel_http_request(&self, id: u64)` in `crates/sixm-js/src/runtime.rs`: remove `id` from `http_cancels` and invoke inside `self.with_ctx(...)` (safe error logging via `tracing::error!(target: "sixm::script", ...)`).
  - Ensure all `http_cancels` entries are cleared in `shutdown()`.

- **`docs/lua-api.md` & `docs/js-api.md`**: document `req.address` (including `sv_proxyIPRanges` resolution) and `req.setCancelHandler(fn)` under `SetHttpHandler`.

- **Tests**:
  - Update any `WebRequest` test structs in `sixm-lua/tests/` and `sixm-js/tests/`.
  - Unit/runtime tests in `crates/sixm-lua/tests/` & `crates/sixm-js/tests/`: `req.address` matches request IP; `req.setCancelHandler` fires on `cancel_http_request(id)` and does NOT fire if `res.send` already ran.
  - Integration tests in `crates/sixm-server/tests/web.rs`:
