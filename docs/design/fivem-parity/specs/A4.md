# Spec A4: ACE and info natives

Lua and JS. Two small `sixm-core` additions (below).

## Names (verified in `native-coverage.tsv`, all `implemented = no`)

`IsAceAllowed` (shared), `GetGameName` (shared), `GetGameBuildNumber` (shared),
`GetInstanceId` (shared), `GetResourceCommands` (shared), `GetPlayerGuid` (server),
`GetPlayerTimeOnline` (server), `GetPlayerFromIndex` (server), `GetHostId` (server),
`SetGameType` (server), `SetMapName` (server). `sources/*.md` does not mention them
individually; the tsv is the authority. **Dropped:** `GetPlayerTeam` (in the tsv but not
in A4's list). Nothing else dropped.

## Decided behavior and availability

| Name | Side | Behavior |
|---|---|---|
| `IsAceAllowed(object)` | server | `ServerHost::is_ace_allowed("resource.<calling resource>", object)`; not registered on clients (no ACE store there) |
| `GetGameName()` | both | constant: server `"sixm"`, client `"headless"` (no adapter name API exists; ignores the `gamename` convar on purpose) |
| `GetGameBuildNumber()` | both | constant `0` |
| `GetInstanceId()` | both | `std::process::id()` as integer (stable per process) |
| `GetResourceCommands(resource)` | both | array of command names registered by that resource, sorted ascending, `{}` if none/unknown (names are lowercase, as stored) |
| `GetPlayerGuid(player)` | server | hex part of the player's `license:` identifier (text after `license:`), `nil` if unknown player or none |
| `GetPlayerTimeOnline(player)` | server | whole seconds (integer, floor) since the server accepted the connection; `nil` for unknown player |
| `GetPlayerFromIndex(index)` | server | 0-based index into `players()` (join order), returned as a decimal string like `GetPlayers`; `nil` if out of range or not a non-negative whole number (read with the existing `player_id`) |
| `GetHostId()` | server | lowest connected player id as string, `nil` if nobody |
| `SetGameType(name)` | server | `set_convar_for_resource(&rt.resource, "gametype", name, ConvarKind::ServerInfo)` (so `/info.json` `vars` shows it); errors as `SetConvar` does |
| `SetMapName(name)` | server | same with `"mapname"` |

## sixm-core changes

1. `Host` (`crates/sixm-core/src/runtime.rs`), after `registered_commands` (l.363), default method:
```rust
/// Names of the console commands that `resource` registered, sorted ascending.
fn resource_commands(&self, _resource: &str) -> Vec<String> {
    Vec::new()
}
```
   Overrides: `ResourceManager` in `sixm-server/src/manager.rs` (next to `registered_commands`, l.1314):
   `self.commands.borrow().iter().filter(|(_, c)| c.handler.owner.as_ref() == resource).map(|(n, _)| n.clone()).collect()`
   (the map is a `BTreeMap`, already sorted); `ClientRuntime` in `sixm-client/src/host.rs` (next to its
   `registered_commands`, l.270) with the same body over its `commands` map; both test hosts
   (`crates/sixm-lua/tests/common/mod.rs`, `crates/sixm-js/tests/common/mod.rs`): add field
   `pub command_owners: RefCell<Vec<(String, String)>>` (`(resource, command)`, tests set it directly)
   and filter + sort it.
2. `ServerHost` (same file, after `player_tokens`, l.600), default method:
```rust
/// How long `player` has been connected, counted from when the server accepted the
/// connection. `None` for an unknown player.
fn player_time_online(&self, _player: u32) -> Option<Duration> {
    None
}
```
   Overrides: `ResourceManager` (`manager.rs`, after `player_last_msg` l.1600) calling new
   `pub(crate) fn player_online_for(&self, player) -> Option<Duration>` in `sixm-server/src/network.rs`
   (next to `player_last_message`, l.963): `Instant::now().saturating_duration_since(found.connected_at)`.
   Add `connected_at: Instant` to `struct Player` (l.131 area, `Instant::now()` in `Player::new`, l.164).
   Both test hosts: field `pub time_online: RefCell<HashMap<u32, Duration>>` (tests set it) and override.
   No other implementors exist.
