## 2. Lua `PerformHttpRequestAwait(url, method, data, headers, options)` (server only)

File `crates/sixm-lua/src/http.rs`. `http::install` runs after `promise::install`
(natives.rs:47 vs :57), so `Await` and `promise` exist when it runs.
- Keep `PerformHttpRequest` as is. After it is built, add a Lua chunk const,
  same pattern as `AWAIT_SOURCE` (`promise.rs:35-52`):
```
const AWAIT_REQUEST_SOURCE: &str = r"
local perform, new, await = ...
local isyieldable, error = coroutine.isyieldable, error
return function(url, method, data, headers, options)
	if not isyieldable() then
		error('PerformHttpRequestAwait can only be called from a thread (Citizen.CreateThread)', 2)
	end
	local p = new()
	perform(url, function(status, body, responseHeaders, errorData)
		p:resolve({ status, body, responseHeaders, errorData })
	end, method, data, headers, options)
	local r = await(p)
	return r[1], r[2], r[3], r[4]
end
";
```
- Build it: `let new: Function = globals.get::<Table>("promise")?.raw_get("new")?;`
  `let await_fn: Function = globals.raw_get("Await")?;`
  `lua.load(AWAIT_REQUEST_SOURCE).set_name("=sixm http await").call::<Function>((perform.clone(), new, await_fn))?`
  and `globals.raw_set("PerformHttpRequestAwait", it)`. Result: `status, body, headers, errorData`
  exactly as the `PerformHttpRequest` callback receives them (network failure:
  status 0, message in `errorData`). Argument errors (bad timeout, bad headers)
  propagate from `perform` as ordinary script errors. Not available on clients
  (installed only inside `http::install`). Update the module doc comment and
  the `install` doc comment of http.rs.

## 3. JS listener aliases (client and server)

File `crates/sixm-js/src/events.rs`.
- `struct Handler` (line 14): add `raw: bool`. `Events::add_handler`
  (line 198) gets a 4th parameter `raw: bool`; the two existing callers (the
  `add_handler` closure, line 52-60, and `register_net_event`, line 96) pass `false`.
- In `install_listeners` add:
  - `addEventListener(name: String, func: Function, net_safe: Opt<bool>)`: if
    `net_safe.0 == Some(true)` call `rt.mark_net_event(&name)`; then add the
    handler (raw false); returns the `{key, name}` handle object (`handle_object`).
  - `addNetEventListener`: register `register_net_event.clone()` under this name
    (identical to `onNet`).
  - `addRawEventListener` and `addRawEventHandler`: one closure
    `(name: String, func: Function)` adding a handler with `raw = true`, returning
    the handle object. It does NOT mark the event net-safe (a network event still
    needs `onNet`/`RegisterNetEvent`, same drop rule as for normal handlers).
  - Add the four names to the `for (name, func) in [...]` array (line 110).
    `removeEventListener`/`RemoveEventHandler` already work for raw handlers.
  - Update the doc comment of `install` (line 38).
- Dispatch (`dispatch_event_in_ctx`, line 279): collect handlers as
  `Vec<(Persistent<Function<'static>>, bool)>`. Before the loop build
  `let raw_payload: Option<Vec<u8>>` lazily, only if some handler is raw:
  `sixm_core::msgpack::pack(&Value::Array(args.to_vec()))` (the payload is the
  msgpack array of the event arguments; one pack per dispatch, shared by all
  raw handlers). If packing fails, log
  `tracing::error!(target: "sixm::script", "[{}] raw event `{event}`: {err}", self.resource)`
  and skip the raw handlers. For a raw handler call the function with exactly
  two arguments: `rquickjs::TypedArray::<u8>::new_copy(js_ctx.clone(), &payload)?.into_value()`
  (as `msgpack.pack` does, `msgpack.rs:34`) and the current `source` global
  (`js_ctx.globals().get::<_, JsValue>("source")?`, read after
  `set_source_global`: `""` local, player id on server, 65535 from server on
  client). Build the Args exactly like the existing normal path.

## Tests

`crates/sixm-lua/tests/http.rs` (helpers `new_host`, `start`, `first`, `tick`
from `common`, `host.http_requests`, `host.call_ref`):
- `perform_http_request_await_returns_the_outcome_from_a_thread`: script
  starts `CreateThreadNow(function() local s,b,h,e = PerformHttpRequestAwait('http://example.test/', 'POST', 'x', {A='1'}, {timeout=500}); result = s..':'..b..':'..h['content-type']..':'..e end)`,
  exports `result`. Assert one request with method `POST`, body `x`, header
  `("A","1")`, timeout 500 ms; before the callback `first` is nil; then
  `host.call_ref(&callback, &[Int(200), "hi", Map(content-type=text/plain), ""])`,
  `tick(&host, Instant::now())` and `first(&runtime,"result") == "200:hi:text/plain:"`.
- `perform_http_request_await_outside_a_thread_is_an_error`: `pcall(PerformHttpRequestAwait, 'http://example.test/')`
  at top level; error contains `can only be called from a thread`; no request recorded.
- `a_client_has_no_perform_http_request_await`: client host, `PerformHttpRequestAwait ~= nil` is false.

`crates/sixm-lua/tests/natives.rs` does not exist; put the Trace test in
`crates/sixm-lua/tests/sides.rs` (look at its helpers):
- `citizen_trace_accepts_text_on_both_sides`: on server and client host,
  `Citizen.Trace('hello\n')` does not raise, `type(Citizen.Trace) == 'function'`,
  and `pcall(Citizen.Trace, {})` is false.

`crates/sixm-js/tests/events_exports.rs` (style of line 8/51):
- `event_listener_aliases_match_on_and_on_net`: `addEventListener("a", fn)` fires on
  `emit("a", 1)`; `addEventListener("b", fn, true)` fires for
  `deliver_event("b", EventSource::Net(7), ...)`; `addEventListener("c", fn)` does
  NOT fire for a Net delivery; `addNetEventListener("d", fn)` fires for Net(7);
  the returned handle works with `RemoveEventHandler`.
- `raw_event_listeners_receive_msgpack_bytes_and_source`: `addRawEventListener("r", (data, src) => ...)`
  records `data instanceof Uint8Array`, `JSON.stringify(msgpack.unpack(data))` and `src`;
  `emit("r", 1, "a")` gives `true`, `[1,"a"]`, `""`; `onNet("rn")` plus
  `addRawEventHandler("rn", ...)` with `deliver_event("rn", EventSource::Net(7), &[Value::from("x")], ..)`
  gives `["x"]` and `7`; an unregistered net event is dropped; `removeEventListener`
  stops it.
