# Spec C1: Client-written state bags — protocol and server

Clients may set replicated keys on their own player bag (`player:<id>`) and on entities they own (`entity:<id>`). The server validates ownership, key/value/frame limits (same limits as server writes), `sv_stateBagStrictMode`, and the rate limit shared with `sv_playerEventRateLimit`, applies the write, runs server change handlers, and relays to other clients.

## Protocol and wire format (`crates/sixm-net`)

1. **`crates/sixm-net/src/protocol.rs`**:
   - Bump `PROTOCOL_VERSION` from `14` to `15`.
   - Add `ClientMessage::SetStateBag { bag: String, key: String, value: StateValue }` with `pub(crate) const SET_STATE_BAG_TAG: u32 = 7`.
2. **`crates/sixm-net/src/wire.rs`**:
   - Append `"SetStateBag"` to `CLIENT_VARIANTS` (index `7`).
   - In `StateVisitor::visit_seq`, validate `bag` and `key` with `1..=MAX_STATE_NAME_LEN` (`checked_name` / `validate_length`) so invalid bag or key lengths are rejected during decoding for both `ClientMessage::SetStateBag` and `ServerMessage::StateBag` / `StateSnapshot`.
   - In `ClientMessageVisitor::visit_enum`, handle `ClientMessage::SET_STATE_BAG_TAG` using `StateSeed { budget: self.budget }`, producing `ClientMessage::SetStateBag { bag, key, value: StateValue(value) }`.
   - Add `pub(crate) fn encode_client_state(bag: &str, key: &str, value: &Value, max_frame: usize) -> Result<Arc<[u8]>, NetError>` using a borrowed serializer struct (`ClientStateFrame` with tag `ClientMessage::SET_STATE_BAG_TAG`) after validating `bag` (`1..=MAX_STATE_NAME_LEN`), `key` (`1..=MAX_STATE_NAME_LEN`), and `check_values(std::slice::from_ref(value))`, enforcing `max_frame`.
   - Add `pub(crate) fn decode_set_state_bag(payload: &[u8]) -> Result<(String, String, Value), NetError>` (decoding a `(bag, key, value)` `StateSeed` with `ValueBudget::default()`) for the dedicated fuzz target.
3. **`crates/sixm-net/src/connection.rs`**:
   - In `before_accepted`, reject `ClientMessage::SetStateBag { .. }` with `"the first message must be Hello"`.
   - Add `Inbound::SetStateBag { bag: String, key: String, value: Value }` and decode `ClientMessage::SetStateBag` in `read_loop` through the shared connection `limiter.admit(now)` to emit `NetEvent::SetStateBag { player, bag, key, value: value.0 }`.
4. **`crates/sixm-net/src/server.rs` and `crates/sixm-net/src/client.rs`**:
   - Add `NetEvent::SetStateBag { player: u32, bag: String, key: String, value: Value }`.
   - Add `Command::BroadcastExcept { frame: Arc<[u8]>, except: u32 }` in `Supervisor::handle` and `pub fn broadcast_encoded_except(&self, frame: Arc<[u8]>, except: u32) -> Result<(), NetError>` on `NetServer`, sending the pre-encoded frame to every connected player whose id != `except`.
   - Add `pub fn send_state(&self, bag: &str, key: &str, value: &Value) -> Result<(), NetError>` on `NetClient` calling `encode_client_state(bag, key, value, MAX_FRAME)` and `self.send_frame(frame)`.

## Server validation, convar, and relay (`crates/sixm-server`)

1. **`crates/sixm-server/src/convars.rs`**:
   - Add `const STATE_BAG_STRICT_MODE: &str = "sv_stateBagStrictMode";` to `CONSOLE_ONLY_CONVARS` (default `false` — `is_truthy(STATE_BAG_STRICT_MODE)` returns `false` unless set to `true` or `1`).
   - Add `pub(crate) fn state_bag_strict_mode(&self) -> bool`.
2. **`crates/sixm-server/src/network.rs`**:
   - Extract `pub(crate) fn admit_player_event(&self, player: u32, kind: &str) -> bool` from `player_event` so both `NetEvent::Event` and `NetEvent::SetStateBag` share `player.event_bucket` and `sv_playerEventRateLimit`.
   - In `handle_net`, handle `NetEvent::SetStateBag { player, bag, key, value }` via `self.touch_player(player); self.client_state_set(player, &bag, &key, value);`.
3. **`crates/sixm-server/src/state.rs` & `scope.rs`**:
   - Parameterize `broadcast_state(&self, bag, key, value, except: Option<u32>)` and scope helpers (`send_entity_state`, `send_state_in_bucket`) with `except: Option<u32>`:
     - Server script writes pass `except = None` (unchanged behavior).
     - Client writes pass `except = Some(player)` so the originating client does not receive an echo of its own write.
   - Add `pub(crate) fn client_state_set(&self, player: u32, bag: &str, key: &str, value: Value)`:
     - Reject (log debug/warn and return without mutating or relaying; do not kick) if `self.convars.borrow().state_bag_strict_mode()` is `true`.
     - Check `!self.admit_player_event(player, "state bag writes")` -> return.
     - Validate `validate_key(key)` and `!value.contains_func_ref()`.
     - Validate ownership:
       - `player_of_bag(bag) == Some(player) && self.network.players.borrow().contains(player)`
       - OR `entity_of_bag(bag).is_some_and(|entity| self.entities.borrow().get(entity).is_some_and(|info| info.owner == Some(player)))`
     - Relay via `self.broadcast_state_except(bag, key, &value, Some(player))` (which validates `MAX_STATE_NAME_LEN`, `MAX_VALUE_DEPTH`, and `MAX_FRAME` via `server.encode_state` before mutating state).
     - Apply to `self.state.borrow_mut().apply(bag, key, &value, true)` and run server change handlers (`runtime.deliver_state_change(bag, key, &value, true)`).
