# Spec A3: state bag natives

Lua and JS, server and client. One `sixm-core` trait method is added.

## Names (verified)

`native-coverage.tsv` rows (apiset `shared`, implemented `no`): `GetStateBagValue`
(l.338), `GetStateBagKeys` (337), `SetStateBagValue` (824), `StateBagHasKey` (913),
`EnsureEntityStateBag` (87). All five are documented; none dropped. Exist already:
`Add/RemoveStateBagChangeHandler`, `GetPlayerFromStateBagName`,
`GetEntityFromStateBagName`.

Semantics (decided):
- Bag names: `global`, `player:<id>`, `entity:<id>` (canonical digits only).
- `GetStateBagValue(bagName, key)` -> value or `nil`/`undefined` (unknown bag or key).
- `StateBagHasKey(bagName, key)` -> boolean (`state_get(..).is_some()`; a key set
  to nil is deleted, so it is false).
- `GetStateBagKeys(bagName)` -> array of key names sorted ascending, `{}` for an
  existing bag without keys, `nil`/`undefined` for an unknown bag (a bag exists by
  the same rule as `state_set`: `global`, a connected player's bag, an existing
  entity's bag; on a client also a bag the mirror already holds, and the local
  player's bag).
- `SetStateBagValue(bagName, key, value, replicated)` -> nothing. Exactly the
  semantics of `bag:set(key, value, replicated)` (same `write` helper, same
  errors: unknown bag `state bag `X` does not exist`, key not 1..=256 bytes,
  `state values cannot contain functions`, nil deletes). Differences: `replicated`
  is a plain boolean, omitted/nil means `false` (FiveM signature; `bag:set`
  defaults to true). Registered on BOTH sides (`shared` in the tsv; this differs
  from the plan text "server only"): on a client `replicated=true` fails with the
  host's existing error "clients cannot write replicated state".
- `EnsureEntityStateBag(entity)` -> nothing. Entity bags exist for the whole life
  of an entity in SixM, so this is a compatibility call that accepts any integer
  and does nothing (no error for a missing entity). Document it so.

## sixm-core trait change

`crates/sixm-core/src/runtime.rs`, trait `Host`, directly after `state_get` (l.348):
```rust
/// Names of the keys set in state bag `bag`, sorted ascending, or `None` when
/// the bag does not exist (the same rule `state_set` uses to reject a bag).
fn state_keys(&self, bag: &str) -> Option<Vec<String>>;
```
Required (no default). Implementors, all must be updated:
1. `sixm-server/src/manager.rs` `impl Host for ResourceManager` (l.1288, after
   `state_get`): `fn state_keys(&self, bag) { self.state_bag_keys(bag) }`. In
   `sixm-server/src/state.rs` add `StateStore::keys(&self, bag) -> Vec<String>`
   (sorted, empty if the bag has no entry) and
   `pub(crate) fn state_bag_keys(&self, bag: &str) -> Option<Vec<String>>` on
   `ResourceManager`: `self.ensure_bag(bag).ok()?;` then `Some(self.state.borrow().keys(bag))`.
2. `sixm-client/src/host.rs` `impl Host for ClientRuntime` (l.219): `self.bag_exists(bag).then(|| self.state.borrow().keys(bag))`;
   add `StateMirror::keys(&self, bag) -> Vec<String>` (sorted) in `sixm-client/src/state.rs`.
3. `crates/sixm-lua/tests/common/mod.rs` `impl Host for TestHost` (l.313) and
4. `crates/sixm-js/tests/common/mod.rs` `impl Host for TestHost` (l.313): bag exists
   when `bag == GLOBAL_BAG` or a connected player (`player_of_bag` in `self.players`) or
   an existing entity (`entity_of_bag` in `self.entities`) (copy the condition from
   that file's `state_set`); keys = `self.state` entries whose bag matches, sorted.
`sixm-core/src/adapter.rs` only forwards `state_get`; no change. No other `Host` impls exist
(grep `impl .*Host for` verified).

## Lua (`crates/sixm-lua/src/state.rs`, `install`, l.131)

Copy the pattern of `player_from_bag` (`bind_fn`). Add before the `raw_set` calls:
```rust
let get_value = bind_fn(lua, weak, |rt, (bag, key): (String, String)| {
    match rt.host()?.state_get(&bag, &key) {
        Some(value) => rt.to_lua(&value),
        None => Ok(LuaValue::Nil),
    }
})?;
let has_key = bind_fn(lua, weak, |rt, (bag, key): (String, String)| {
    Ok(rt.host()?.state_get(&bag, &key).is_some())
})?;
let get_keys = bind_fn(lua, weak, |rt, (bag,): (String,)| {
    rt.host()?.state_keys(&bag).map(|keys| rt.lua.create_sequence_from(keys)).transpose()
})?;
let set_value = bind_fn(lua, weak, |rt, (bag, key, value, replicated): (String, String, LuaValue, bool)| {
    write(rt, &bag, &key, &value, replicated)
})?;
let ensure_entity = bind_fn(lua, weak, |_, (_entity,): (i64,)| Ok(()))?;
```
(`Option<Table>` returns nil for None.) Register as globals `GetStateBagValue`,
`StateBagHasKey`, `GetStateBagKeys`, `SetStateBagValue`, `EnsureEntityStateBag`.
Update the module/`install` doc comments.
