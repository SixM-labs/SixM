# Spec D4: Proxy IP ranges (`sv_proxyIPRanges`) and `/metrics` Basic Auth

Harden HTTP rate limiting, client IP attribution, and Prometheus `/metrics` exposure.

## 1. Pure-Rust CIDR matching and `TrustedProxies` (`crates/sixm-net/src/web.rs` & `lib.rs`)

- Implement `IpCidr` (`V4 { network: u32, mask: u32 }`, `V6 { network: u128, mask: u128 }`) with **zero external dependencies**:
  - `IpCidr::parse(spec: &str) -> Result<Self, &'static str>`:
    - Parses CIDR (`a.b.c.d/n`, `::/n`) or bare IP (`127.0.0.1` -> `/32`, `::1` -> `/128`).
    - Rejects empty strings, invalid IP addresses, and prefix lengths `> 32` (IPv4) or `> 128` (IPv6).
    - Masks host bits on construction (`addr & mask`).
  - `IpCidr::contains(&self, ip: IpAddr) -> bool`:
    - Normalizes IPv4-mapped IPv6 (`::ffff:a.b.c.d`) to `IpAddr::V4` (and compares IPv4 against IPv4 CIDRs) so dual-stack sockets work identically on Linux and Windows.
- Implement `TrustedProxies` (`Clone`, `Debug`, `Default`):
  - Backed by `has_ranges: Arc<AtomicBool>` (lock-free fast path when unset/empty) and `ranges: Arc<RwLock<Vec<IpCidr>>>`.
  - `set_ranges(&self, ranges: Vec<IpCidr>)` and `parse_and_set(&self, raw: &str) -> Vec<String>` (splits on ASCII whitespace and commas, collects any invalid entries to return for warnings, applies valid entries cleanly).
  - `resolve_ip<'a>(&self, peer_ip: IpAddr, headers: impl IntoIterator<Item = (&'a str, &'a str)>) -> IpAddr`:
    - If `!self.has_ranges.load(Ordering::Relaxed)`, return `peer_ip` immediately without locking.
    - Read `ranges`; if `peer_ip` does NOT match any range, return `peer_ip` (never trust forwarded headers from untrusted peers).
    - When `peer_ip` IS trusted:
      - Inspect `x-forwarded-for` (case-insensitive, supporting multiple header occurrences joined/scanned right-to-left): iterate comma-separated trimmed tokens from right to left. For each token parsed as `IpAddr`:
        - If it fails to parse as `IpAddr`, stop scanning further left (defends against malformed left-side header injection) and fall through to `X-Real-IP` / `peer_ip` unless a valid untrusted IP was already seen to the right.
        - Track the leftmost valid trusted IP seen continuously from the right; return the first (rightmost) valid `IpAddr` NOT matching `ranges`. If all valid tokens are trusted proxies, return the leftmost valid token.
      - Else inspect `x-real-ip` (case-insensitive): if its trimmed value parses as `IpAddr`, return it.
      - Else return `peer_ip`.
- Wire `TrustedProxies` into `sixm-net::web`:
  - Add `WebServer::bind_with_proxies(addr: SocketAddr, proxies: TrustedProxies, on_request: impl Fn(WebExchange) + Send + Sync + 'static) -> io::Result<Self>` and `pub fn trusted_proxies(&self) -> &TrustedProxies`, keeping `WebServer::bind(addr, on_request)` backwards-compatible.
  - Inside `answer()`, resolve `client_ip` using `trusted_proxies` BEFORE calling `rate_limits.admit(client_ip, Instant::now())` so `sv_proxyIPRanges` governs `sixm-net` per-IP HTTP rate limiting!
  - Store both `peer_ip: IpAddr` and `client_ip: IpAddr` on `WebResponder` (`pub fn peer_ip(&self) -> IpAddr`, `pub fn client_ip(&self) -> IpAddr`).
  - Helper `pub fn http_client_identifier(ip: IpAddr) -> String` (or `format!("ip:{client_ip}")`) using `ip:` prefix.
  - Export `IpCidr` and `TrustedProxies` from `crates/sixm-net/src/lib.rs`.

## 2. Server convars & `/metrics` Basic Auth (`crates/sixm-server`)

- **`crates/sixm-server/src/convars.rs`**:
  - Add console-only convars (`CONSOLE_ONLY_CONVARS` `[&str; 17]`):
    - `PROXY_IP_RANGES = "sv_proxyIPRanges"`
    - `PROMETHEUS_BASIC_AUTH_USER = "sv_prometheusBasicAuthUser"`
    - `PROMETHEUS_BASIC_AUTH_PASSWORD = "sv_prometheusBasicAuthPassword"`
  - Store `prometheus_password: Option<String>` on `Convars` outside `values` (matching `rcon_password`, so `GetConvar("sv_prometheusBasicAuthPassword", ...)` NEVER exposes the password to scripts, and `add_reader` rejects it).
  - Add `Convars::set_prometheus_password(&mut self, password: &str)`, `Convars::prometheus_basic_auth(&self) -> Option<(&str, &str)>` (or `prometheus_auth_configured(&self) -> bool` + `check_prometheus_basic_auth(&self, header: Option<&str>) -> bool`).
    - Behavior:
      - If BOTH `sv_prometheusBasicAuthUser` and `sv_prometheusBasicAuthPassword` are unset or empty: Basic Auth is disabled (`/metrics` works whenever `sv_metricsEnabled` is truthy).
      - If EITHER is non-empty: Basic Auth is enabled. Require an `Authorization: Basic <base64>` header (accept case-insensitive `"Basic "` scheme) whose decoded `"user:password"` matches BOTH configured user and password (when only one of user/password is set while the other is empty, deny all requests fail-closed so half-configured credentials never accidentally open `/metrics`!). Compare via constant-time SHA-256 + `subtle::ConstantTimeEq` so timing does not leak username/password length or contents.
    - Pure-Rust RFC 4648 base64 encode (for `"user:password"` -> expected header digest) without adding external crate dependencies.
- **`crates/sixm-server/src/manager.rs` & `network.rs`**:
  - In `ResourceManager::set_convar`:
    - Handle `PROMETHEUS_BASIC_AUTH_PASSWORD` like `RCON_PASSWORD` (`Plain` only; update `convars.set_prometheus_password(value)` and return `Ok(())` without writing to `convars.values` or delivering convar listeners).
    - When `name.eq_ignore_ascii_case(PROXY_IP_RANGES)`: parse `value` into `self.network.trusted_proxies` and log `warn!` for any invalid CIDR token.
  - Hold `pub(crate) trusted_proxies: TrustedProxies` on `Network` (initialized with current `convars` on `WebServer::bind_with_proxies` so `server.cfg` entries before `endpoint_add_udp` apply immediately).
- **`crates/sixm-server/src/web.rs`**:
  - Replace `responder.peer_ip()` with `responder.client_ip()` in `handle_rcon` (`RconGuard` tracks the proxy-resolved client IP / `ip:<addr>`!).
  - Format `ip:{}` client identifiers in RCON auth/lockout logs (e.g. `debug!("rejected unauthorized RCON attempt from ip:{client_ip}")` and `warn!("locked out RCON requests from ip:{client_ip} after repeated failures")`), and use `responder.client_ip()` when building future `WebRequest` fields.
  - In `handle_metrics(&self, request: &WebRequest)`:
    - First check `sv_metricsEnabled` (`404 Not Found` if disabled) and HTTP method (`GET`/`HEAD`, else `405`).
    - Check Basic Auth via `convars.check_prometheus_basic_auth(auth_header)`:
      - When required and missing/invalid, return `401 Unauthorized` with header `("www-authenticate", "Basic realm=\"SixM Metrics\"")`.

## 3. Docs, Changelog, and Tests

- `docs/server.md`: document `sv_proxyIPRanges`, `sv_prometheusBasicAuthUser`, and `sv_prometheusBasicAuthPassword` (noting console-only restriction, right-to-left untrusted XFF hop selection, `ip:` identifier / rate-limit attribution, and Basic Auth behavior on `/metrics`).
- `CHANGELOG.md`: Unreleased entry for D4.
- Tests:
  - `crates/sixm-net/src/web.rs` unit tests for `IpCidr` parsing/matching (IPv4, IPv6, IPv4-mapped IPv6, invalid masks/hosts) and `TrustedProxies::resolve_ip` (untrusted peer ignores XFF/X-Real-IP, trusted peer strips right-to-left trusted hops, rejects malformed spoofed XFF, falls back to X-Real-IP).
  - `crates/sixm-server/tests/web.rs` integration tests:
    - Trusted proxy loop (`127.0.0.1/32`): forwarding distinct `X-Forwarded-For` / `X-Real-IP` IPs isolates rate limits (`429` triggers per forwarded client IP rather than blocking other forwarded IPs, and RCON lockout isolates by forwarded IP!), whereas without `sv_proxyIPRanges` spoofed `X-Forwarded-For` is ignored and rate limit still hits the peer IP.
    - `/metrics` Basic Auth: missing/wrong credentials return `401` with `WWW-Authenticate`, half-configured user without password returns `401`, valid `Basic` credentials return `200`, and scripts cannot read `sv_prometheusBasicAuthPassword` via `GetConvar`.
